# Security Policy

## Reporting a vulnerability

**Please do not report security vulnerabilities through public issues, discussions or pull requests.**

Report them privately instead, using one of the following channels:

- Email: [security@tamboai.co](mailto:security@tamboai.co) (TAMBO ai, project maintainers);
- GitHub: use *Security → Report a vulnerability* on this repository (private vulnerability reporting);
- Eclipse Foundation Security Team: [security@eclipse.org](mailto:security@eclipse.org) — see the [Eclipse Vulnerability Reporting Policy](https://www.eclipse.org/security/).

Please include as much of the following as possible:

- the affected component (`shared`, `tmodeler-ksp`, …), platform and version;
- a description of the issue and its impact;
- the steps (or a minimal sample) needed to reproduce it.

## What to expect

- an acknowledgement of your report;
- an assessment and, if confirmed, a fix prepared privately;
- a coordinated disclosure: the vulnerability is published once a fixed release is available.

## Supported versions

Only the latest released version receives security fixes.

| Version | Supported |
|---|---|
| Latest release (`1.0.x`) | ✅ |
| Older releases | ❌ |
